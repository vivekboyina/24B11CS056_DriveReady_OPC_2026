# Day 1 – Agentic AI Workshop 🚀

## About the Workshop

This repository documents my learning journey through the **Agentic AI Workshop**, organized by the **Department of Technical Training (DOTT)** at our college.

Day 1 focused on understanding how to interact with Large Language Models (LLMs), configure an AI-powered assistant, and explore basic AI safety mechanisms.

## 📚 Topics Covered

- Introduction to Large Language Models (LLMs).
- Connecting to LLMs using LangChain.
- Integrating Groq API with Python.
- Configuring system prompts and controlling AI responses.
- Building a basic AI assistant for a home bakery.
- Introduction to Prompt Injection and AI safety.
- Exploring Meta Llama Prompt Guard.

## 🛠️ Technologies Used

- Python
- Google Colab
- LangChain
- Groq API
- OpenAI GPT-OSS 120B
- Meta Llama Prompt Guard 2

## 💻 Practical Implementation

### 1. LLM Integration

Installed and imported `langchain_groq` to connect with Groq-hosted language models.

### 2. Building an AI Bakery Assistant

Created a basic AI assistant for **Sweet Crumbs Home Bakery** using a system prompt.

The assistant was configured with specific business information and instructions:

- Orders require 24 hours' notice.
- Eggless cake options are available.
- Never promise delivery times without confirmation.
- Respond politely in under 60 words.

### 3. Testing the AI Assistant

Created an `ask()` function to send user questions to the LLM and retrieve responses.

### 4. Exploring AI Safety

Explored Meta Llama Prompt Guard 2 to understand prompt injection detection and the importance of protecting AI systems against malicious instructions.

## 🎯 Key Learnings

- How to connect Python applications with LLMs.
- How system prompts influence AI behavior.
- How to build a basic domain-specific AI assistant.
- Why prompt injection is a concern in AI applications.
- The importance of AI safety and responsible AI development.
